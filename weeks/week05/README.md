## แนวคิดหลัก

- แยก style, framework, viewpoint และ notation
- รู้จักแนวคิด 4+1 และ enterprise architecture/TOGAF เพื่อเห็นระดับขอบเขต
- ใช้ arc42 เป็นแนวเลือกสาระเอกสาร และ C4 สื่อสาร Context/Container พร้อม Dynamic หรือ Sequence

## กิจกรรมในแล็บ

- วาด Context และ Container ของระบบที่ใช้อยู่ อธิบาย flow สำคัญหนึ่งเส้น
- จับคู่แผนภาพกับไฟล์และหน่วยรัน
- อ่าน Dockerfile/Compose ที่เตรียมไว้ แล้วแก้ port หรือ config เล็กน้อย
- ฝึกอธิบายสั้น ๆ ทั้งภาษาไทยและอังกฤษ

## เสริมพื้นฐาน (30–45 นาทีในเวลาปฏิบัติ)

draw.io และสัญลักษณ์ C4, การอ่าน Dockerfile/Compose, ตัวแปร environment
