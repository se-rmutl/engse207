```bash
# Windows รันในเทอร์มินัล Ubuntu (WSL) ไม่ใช่ PowerShell · macOS รันใน Terminal
cd ~
curl -fsSL https://raw.githubusercontent.com/se-rmutl/engse207/main/weeks/week01/check-docker.sh -o check-docker.sh
bash check-docker.sh
```

ผลที่ผ่านคือ `สรุป: ผ่าน 5 จาก 5` (Windows) หรือ `สรุป: ผ่าน 4 จาก 4` (macOS)
ถ้ายังไม่ผ่าน ดูคำแนะนำที่สคริปต์พิมพ์ออกมาและ[ตารางแก้ปัญหาในคู่มือ](https://se-rmutl.github.io/engse207/docker.html#trouble) จดอาการและข้อความ error ลงไฟล์ I01 ใช้เครื่องเพื่อนในทีมไปก่อน แล้วแจ้งในกลุ่ม LINE ของ SEC ก่อนคาบ T02
