## แนวคิดหลัก

- IaaS/PaaS/SaaS และ managed service
- ความรับผิดชอบของผู้พัฒนา การแยก build กับ runtime
- environment, network, storage, secrets, logs และค่าใช้จ่าย
- ใช้ Railway เป็นเส้นทางฝึกหลัก

## กิจกรรมในแล็บ

- นำ baseline เดิมขึ้น Cloud ด้วย Git และ Dockerfile
- ตรวจ UI → API → PostgreSQL และข้อมูลหลัง restart
- วาด Deployment Diagram
- รับสถานการณ์ผู้ให้บริการทีมเล็กที่งบหรือจำนวนผู้ดูแลเปลี่ยน แล้วระบุทักษะที่ต้องเรียนรู้ต่อ

## เสริมพื้นฐาน (30–45 นาทีในเวลาปฏิบัติ)

Git push → build, Dockerfile แยก build กับ runtime, ตั้งค่า env/secrets บน Cloud, อ่าน deploy log

## หลักฐานและการประเมิน

- หลักฐาน Cloud ใน **ARCH-04** และ Deployment ใน **ARCH-02** (เก็บเข้า A6 ตอน T14)
- โจทย์การปรับบริการใช้ต่อใน A9

## ศึกษาด้วยตนเอง 5 ชั่วโมง

- อ่านเอกสาร deploy 1 ชม.
- ตรวจและแก้ deployment 3 ชม.
- บันทึกข้อจำกัดและทักษะที่ต้องพัฒนา 1 ชม.
