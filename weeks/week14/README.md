## แนวคิดหลัก

- scenario-based evaluation และ ATAM แบบแนะนำ
- sensitivity, trade-off, risk และ technical debt
- การเลือกตัววัด เงื่อนไขควบคุม ข้อมูลดิบ ค่ากลาง อัตราสำเร็จ และข้อจำกัดการอนุมาน

## กิจกรรมในแล็บ

- ทีมทดลองสองสถานการณ์ที่ตั้งไว้ เปรียบเทียบก่อน–หลังหรือสองแบบด้วยเงื่อนไขเทียบเคียง
- มีข้อมูลเชิงตัวเลขอย่างน้อยหนึ่งเรื่อง ทบทวนผลกับเพื่อน
- ทำ A2b อ่านข้อมูลรายคน แล้วเลือกการปรับที่สำคัญหนึ่งจุด

## หลักฐานและการประเมิน

- **A2b** 3 คะแนน (CLO5, รายคน)
- **ARCH-05** ฉบับร่าง พร้อมผลดิบ หน่วย เงื่อนไข และข้อจำกัด

## ศึกษาด้วยตนเอง 5 ชั่วโมง

- ตรวจข้อมูลและคำนวณ 1 ชม.
- ปรับ ARCH-05 3 ชม.
- วางแผนปรับรุ่นส่งมอบ 1 ชม.
