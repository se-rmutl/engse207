## แนวคิดหลัก

- relational กับ document model, data ownership, consistency และขอบเขต transaction
- เปรียบเทียบ PostgreSQL กับ MongoDB จากรูปข้อมูลและรูปแบบการเข้าถึง
- ไม่สรุปว่าการใช้หลายฐานข้อมูลดีกว่าเสมอ

## กิจกรรมในแล็บ

- ใช้ adapter และโมดูลบันทึกกิจกรรมที่เตรียมไว้ ทดลองอ่านเขียน MongoDB และเทียบทางเลือก PostgreSQL
- แก้ query หรือ payload เล็กน้อย ตรวจข้อมูลและข้อผิดพลาด
- บันทึกการตัดสินใจแบบสั้นเรื่องข้อมูล

## เสริมพื้นฐาน (30–45 นาทีในเวลาปฏิบัติ)

คำสั่ง MongoDB พื้นฐานเทียบกับ SQL, แนวคิด adapter

## หลักฐานและการประเมิน

- บันทึกการตัดสินใจเรื่องข้อมูลใน **ARCH-03** และผลทดลอง MongoDB
- ไม่บังคับ deploy ฐานข้อมูลทั้งสองบน Cloud

## ศึกษาด้วยตนเอง 5 ชั่วโมง

- อ่านตัวอย่าง schema/query 1 ชม.
- ทดลองและตรวจผล 3 ชม.
- เขียนบันทึกทางเลือกข้อมูล 1 ชม.
